# Test Plan - SauceDemo

## 1. Introduction

This document describes the testing approach, scope, objectives, resources, and activities required to test the SauceDemo web application.

**Application:** https://www.saucedemo.com/

**Project Type:** E-commerce Web Application

**Testing Type:** Manual Testing

**Role:** Junior Manual QA Engineer

## 2. Test Objectives

The objectives of this testing project are:

- Verify that the application works according to expected requirements.
- Validate user authentication functionality.
- Verify product catalog functionality.
- Test product sorting functionality.
- Validate shopping cart operations.
- Verify the checkout process.
- Identify and document defects.
- Evaluate the overall quality of the application.

## 3. Scope of Testing

### In Scope

The following functionalities will be tested:

| Module | Description |
|---|---|
| Login | User authentication and validation |
| Products | Product catalog and product information |
| Sorting | Product sorting functionality |
| Cart | Adding and removing products |
| Checkout | Order processing |
| Logout | User logout functionality |
| Reset App State | Application state reset |

### Out of Scope

- Security penetration testing.
- Performance and load testing.
- Payment gateway integration.
- Backend code testing.
- Mobile application testing.

## 4. Test Approach

Testing will be performed manually using the following approaches:

- Functional Testing
- Positive Testing
- Negative Testing
- Exploratory Testing
- UI Testing
- Regression Testing

Test cases will be executed based on predefined expected results.

## 5. Test Environment

| Component | Description |
|---|---|

## 6. Entry Criteria

Testing can start when:

- The application is accessible.
- The test environment is available.
- Test data is prepared.
- Testing scope is defined.

## 7. Exit Criteria

Testing can be considered complete when:

- All planned test cases have been executed.
- Test results have been documented.
- Identified defects have been reported.
- Critical defects have been reviewed.
- Test Summary Report has been prepared.

## 8. Deliverables

The following deliverables will be prepared:

1. Test Plan
2. Test Cases
3. Test Checklists
4. Bug Reports
5. Test Execution Report
6. Test Summary Report

## 9. Risks and Assumptions

### Risks

- Application availability issues.
- Unexpected application behavior.
- Limited testing time.
- Changes in application functionality.

### Assumptions

- SauceDemo is used as a demonstration application.
- Testing is performed in a controlled environment.
- Demo user accounts are available.
- The application is accessible through a web browser.
